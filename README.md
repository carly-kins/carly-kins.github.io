# Carly's Portfolio
My personal Portfolio built with Gatsby. I am going to try to add features to this as time allows, so check back for updates! 

## ✨ Quick start

1.  **Start developing.**

    Navigate into your new site’s directory and start it up.

    ```shell
    npm run develop
    ```

2.  **Open the code and start customizing!**

    Your site is now running at http://localhost:8000!

    Edit `src/pages/index.js` to see your site update in real-time!

3.  **Run a production build**

    ```shell
    npm run build
    ```

    Then to serve:

    ```shell
    npm run serve
    ```
